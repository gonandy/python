# CONTROLE FINANCEIRO 💰

Sistema simples de controle financeiro desenvolvido em **Python**, permitindo registrar receitas e despesas, listar movimentações e acompanhar o saldo.

## CONCEITOS APLICADOS 🐍

- Variáveis e tipos de dados
- Condicionais e estruturas de repetição
- Listas e dicionários
- Funções
- Entrada e saída de dados
- Operações matemáticas

## OBJETIVO 🚀

Projeto desenvolvido para colocar em prática os fundamentos de Python e acompanhar minha evolução na programação.
